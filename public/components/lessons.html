Arsitektur Smart Dual-Routing & Hemat Kuota Helius
1. Pemisahan Trafik Baca vs Eksekusi
Query polling rutin seperti cek saldo wallet, token accounts, dan PnL pooler memakai Solana Public Mainnet sehingga kredit Helius free tier tidak terbuang. Transaksi eksekusi tetap memakai Helius / Alchemy dengan latency terendah.
2. Seamless Fallback & Cooldown 60s
Jika Solana Public Mainnet terkena limit (429) saat polling burst, koneksi seketika berpindah ke Helius / Alchemy secara otomatis tanpa jeda. Setelah 60 detik cooldown berakhir, bot kembali memakai Public Solana.
3. Multi-Node Eksekusi Transaksi
Jika kuota Helius Primary habis saat eksekusi swap, order otomatis dialihkan ke Helius Backup Keys atau Alchemy Backup yang terdaftar di .env.
